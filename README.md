# homebrew-tap

```
brew install deancureton/tap/snipsmith
```

- [snipsmith](https://github.com/deancureton/snipsmith) — manage latex snippets for obsidian, vscode, and neovim from one yaml file
- [tex messages](https://github.com/deancureton/tex-messages) — imessage for macos, but with latex in your bubbles
